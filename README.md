# Lab 06: Category-Partition ба PICT

**Оюутны нэр:** Т.Мөнхцэцэн  
**Оюутны код:** B232270025

## 1. Ажлын орчин

## Зорилго

Энэ лабораторийн ажлаар банкны шилжүүлгийн функцэд
Category-Partition аргаар тестийн сонголт, төлөөлөх утга,
хязгаарлалт болон спецификаци боловсруулна. Мөн Microsoft
PICT ашиглан pairwise covering array үүсгэж, гараар
боловсруулсан тестийн загвартай харьцуулна.

## Хэсэг A. Category-Partition

### A1. Сонголт ба төлөөлөх утгууд

| Category     | Сонголт         | Төлөөлөх утга                             | Тайлбар                            |
| ------------ | --------------- | ----------------------------------------- | ---------------------------------- |
| From account | Valid           | Байгаа, царцаагаагүй данс                 | Шилжүүлэг эхлүүлэх боломжтой       |
| From account | Frozen          | Байгаа боловч царцаасан данс              | Шилжүүлэг хийх эрхгүй              |
| From account | Missing         | Байхгүй дансны ID                         | Эхлэх данс олдохгүй                |
| To account   | Valid           | Байгаа, `from`-оос өөр данс               | Хүлээн авагч хүчинтэй              |
| To account   | Missing         | Байхгүй дансны ID                         | Хүлээн авагч олдохгүй              |
| To account   | SameAsFrom      | `from`-той ижил дансны ID                 | Өөр рүүгээ шилжүүлэх оролдлого     |
| Amount       | Normal          | Эерэг, үлдэгдэл ба лимитэд багтах дүн     | Амжилттай шилжүүлэх боломжтой      |
| Amount       | Zero            | `0`                                       | Эерэг биш дүн                      |
| Amount       | Negative        | `0`-ээс бага дүн                          | Хүчинтэй бус дүн                   |
| Amount       | OverBalance     | Хөрвүүлсний дараах дүн үлдэгдлээс их      | Хүрэлцэхгүй үлдэгдэл               |
| Amount       | OverLimit       | Хөрвүүлсний дараах дүн өдрийн лимитээс их | Өдрийн лимит хэтэрсэн              |
| Currency     | Same            | Дансны валюттай ижил                      | Хөрвүүлэлт шаардлагагүй            |
| Currency     | Different       | Дансны валютаас өөр                       | Хөрвүүлэлт шаардлагатай            |
| Daily limit  | Available       | Лимитэд хангалттай зайтай                 | Дүн лимитэд багтана                |
| Daily limit  | NearlyExhausted | Үлдсэн лимит бага                         | Шилжүүлэг лимит хэтрүүлж болзошгүй |
| Daily limit  | Exhausted       | Өдрийн лимит дууссан                      | Эерэг шилжүүлэг лимит хэтрүүлнэ    |

Шалгах функц:

`POST /transfer`

Оролтын параметрүүд: `from`, `to`, `amount`, `currency`.

### A2. Хязгаарлалт ба алдааны давуу эрэмбэ

Олон алдаа зэрэг илэрсэн үед хүлээгдэх үр дүнг нэг мөр
тодорхойлохын тулд дараах давуу эрэмбийг сонгов:

1. `ERROR_NO_FROM`
2. `ERROR_FROZEN`
3. `ERROR_NO_TO`
4. `ERROR_SAME_ACCOUNT`
5. `ERROR_BAD_AMOUNT`
6. `ERROR_INSUFFICIENT`
7. `ERROR_LIMIT`

Энэ эрэмбээр эхэлж шалгагдах нөхцөлийн алдааг тухайн
хүсэлтийн хүлээгдэх үр дүн гэж үзнэ. Энэ нь лабораторийн
тестийн загвар гаргахад зориулсан таамаглал.
